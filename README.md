# cncd — веб-пульт ЧПУ на Raspberry Pi

Raspberry Pi подключается к плате станка по USB, держит последовательный порт
и раздаёт по Wi-Fi веб-интерфейс: ручное перемещение, координаты, консоль,
загрузка и выполнение G-кода, просмотр траектории, правка настроек GRBL.

Рассчитано на **GRBL 1.1** (LUNYEE 3018 Pro Ultra / Monport и любые совместимые платы).

```
┌───────────┐   Wi-Fi    ┌─────────────┐   USB    ┌────────────┐
│ телефон / │ ─────────► │ Raspberry   │ ───────► │ плата GRBL │
│ ноутбук   │  :8080     │ Pi 3 · cncd │  115200  │   станка   │
└───────────┘            └─────────────┘          └────────────┘
```

## Установка на Pi

Скопируйте каталог на Pi и запустите установщик:

```bash
rsync -a ~/cnc-pi/ pi@raspberrypi.local:~/cnc-pi/
ssh pi@raspberrypi.local
cd ~/cnc-pi && bash install.sh
sudo reboot        # чтобы применилась группа dialout
```

Интерфейс: `http://<ip-адреса-pi>:8080` (или `http://raspberrypi.local:8080`).

### Вручную, без установщика

```bash
sudo usermod -aG dialout $USER
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
./venv/bin/python cncd.py --port /dev/ttyUSB0 --baud 115200
```

### Проверка без станка

```bash
./venv/bin/python cncd.py --simulate --http-port 8080
```

Поднимается встроенный эмулятор GRBL: отвечает `ok`, ведёт координаты,
исполняет перемещения — можно щёлкать весь интерфейс на любом компьютере.

## Ключи запуска

| ключ | переменная окружения | по умолчанию | смысл |
|---|---|---|---|
| `--port` | `CNC_PORT` | автопоиск | последовательный порт станка |
| `--baud` | `CNC_BAUD` | 115200 | скорость порта |
| `--http-port` | `CNC_HTTP_PORT` | 8080 | порт веб-интерфейса |
| `--host` | — | 0.0.0.0 | адрес прослушивания |
| `--token` | `CNC_TOKEN` | пусто | пароль-токен на вход |
| `--simulate` | — | выкл. | эмулятор вместо станка |

При автопоиске берётся первый из `/dev/ttyUSB*`, `/dev/ttyACM*`. Если к Pi
подключено несколько USB-устройств, задайте порт явно или пропишите постоянное
имя через udev — файл `99-grbl.rules`:

```bash
lsusb                                   # найдите VID:PID платы
sudo cp 99-grbl.rules /etc/udev/rules.d/ # поправив VID/PID внутри
sudo udevadm control --reload && sudo udevadm trigger
# после этого используйте --port /dev/cnc
```

## Пароль

По умолчанию интерфейс открыт всем в локальной сети. Чтобы закрыть:

```bash
CNC_TOKEN=мой-пароль ./venv/bin/python cncd.py
```

Заходить по `http://pi:8080/?token=мой-пароль` — токен сохранится в cookie на 30 дней.
Это защита от случайного захода соседа по сети, а не полноценная авторизация:
**не выставляйте порт в интернет**. Для доступа снаружи используйте VPN
(WireGuard/Tailscale).

## Управление службой

```bash
sudo systemctl status cncd
sudo systemctl restart cncd
journalctl -u cncd -f          # живой лог
```

## Интерфейс

**Шапка** — состояние станка (простой / работа / пауза / АВАРИЯ), кнопки
`Разблок.` (`$X`), `Home` (`$H`), `Пауза` (feed hold), `Пуск` (cycle start)
и красная `СТОП` — мягкий сброс контроллера (Ctrl-X).

**Координаты** — переключение «Деталь / Станок» (рабочие координаты и
машинные), обнуление осей по отдельности и всех сразу (`G10 L20 P0`).

**Ручное перемещение** — восемь направлений XY, отдельно Z, выбор шага
(0.01…50 мм) и подачи. Джог идёт командой `$J=`, поэтому его можно отменить
в любой момент, не сбрасывая контроллер (центральная кнопка ■).

Горячие клавиши: стрелки — XY, `PgUp`/`PgDn` — Z, `1`…`6` — шаг,
`Пробел` — пауза/продолжить, `Esc` — сброс. Отпускание клавиши шлёт отмену джога.

**Задание** — загрузка файлов (кнопка или перетаскивание), список, запуск,
удаление. Во время работы: прогресс по *подтверждённым* строкам, время и
оценка остатка, пауза и прерывание.

**Траектория** — проекция XY: рабочие ходы сплошной зелёной, холостые —
пунктиром, кружок с перекрестием — текущее положение инструмента.
Мышь: колесо — масштаб, перетаскивание — панорама, «Вписать» — вернуть обзор.
Разбираются G0/G1/G2/G3, G90/G91, G20/G21, дуги через I/J и R.

**Консоль** — весь обмен со станком; `»` отправлено, `«` принято.
Ошибки `error:N` и `ALARM:N` расшифровываются по-русски. Внизу — поле для
ручной команды и кнопки частых команд.

**Настройки GRBL** — вкладка рядом с консолью: `$$` читается в таблицу с
описанием каждого параметра на русском, правите нужные поля и жмёте
«Записать изменённые» (пишется в EEPROM платы).

## Как устроен стриминг

Используется протокол подсчёта символов GRBL: в контроллер отправляется
столько строк, сколько влезает в его 128-байтовый приёмный буфер, и на каждый
`ok` освобождается место под следующую. Планировщик станка всегда загружен,
поэтому движение идёт без рывков на стыках отрезков — в отличие от наивной
схемы «строка → ждём ok → следующая».

Комментарии и пробелы вырезаются перед отправкой — это экономит буфер.
Ручные команды из консоли и джог встают в очередь **впереди** строк задания.
Прогресс считается по строкам, на которые пришёл `ok`, а не по отправленным,
поэтому полоса не убегает вперёд реального положения фрезы.

## Замечания по безопасности работы

* Пока идёт задание, кнопка `СТОП` делает мягкий сброс — станок остановится
  мгновенно, но **потеряет позицию**; после этого нужен `$X`, а при наличии
  концевиков — повторный `$H`.
* Плавная остановка — `Пауза` (feed hold), затем `Пуск`.
* Wi-Fi может отвалиться. Задание при этом **не прерывается**: файл читается
  на самой Pi, браузер только показывает картинку. Достаточно переоткрыть
  страницу — состояние подхватится.
* Не выключайте Pi во время работы станка.
* Питание Pi 3 — от отдельного адаптера 5 В / 2.5 А, не от платы станка.

## Файлы

```
cncd.py            сервер: порт, стриминг, HTTP/WebSocket API, эмулятор GRBL
static/index.html  разметка интерфейса
static/style.css   тёмная тема, адаптив под телефон
static/app.js      WebSocket-клиент, джог, парсер G-кода, отрисовка траектории
gcode/             сюда попадают загруженные файлы
cncd.service       юнит systemd
99-grbl.rules      udev-правило для постоянного имени /dev/cnc
install.sh         установка на Pi одной командой
```

## HTTP API

| метод | путь | тело / смысл |
|---|---|---|
| GET | `/ws` | WebSocket: состояние 5 раз/с, лог; приём `{t:"cmd"\|"rt"\|"jog"}` |
| POST | `/api/command` | `{"line":"G0X10"}` — строка в очередь |
| POST | `/api/realtime` | `{"name":"hold"}` — hold, resume, reset, jog_cancel, feed_p10… |
| POST | `/api/jog` | `{"axes":{"X":10},"feed":1000}` |
| POST | `/api/zero` | `{"axes":["X","Y"]}` |
| POST | `/api/job` | `{"action":"start\|pause\|resume\|stop","name":"f.nc"}` |
| GET/POST | `/api/settings` | чтение `$$` / запись `{"values":{"120":"50"}}` |
| GET/POST | `/api/files` | список / загрузка (multipart) |
| GET/DELETE | `/api/files/{имя}` | содержимое / удаление |
